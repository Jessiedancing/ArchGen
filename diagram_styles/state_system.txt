# 适用

# 要求
- 只依据原文，不编造

- 每条转移标注触发条件或事件
- 状态名用业务原词，简短稳定
- 状态 ≤ 15
- **第一行必须是** `%% 中文主题名`（如 `%% 订单生命周期`），禁止写成「状态机图」这种通名
