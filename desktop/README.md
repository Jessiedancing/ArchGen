# ArchGen 绿色版说明

给同事发安装包时，用对应平台那一份（打包脚本会把它写成 zip 根目录的 `README.md`）：

- Windows 用户 → [README-win.md](README-win.md) → 产物 `ArchGen-win-green-v0.4.0.zip`
- Mac 用户 → [README-mac.md](README-mac.md) → 产物 `ArchGen-mac-green-v0.4.0.zip`

从本仓库 git clone 的 Windows 用户：先双击根目录 `首次安装依赖.bat`，再双击 `启动 ArchGen.bat`，设置填法见 README-win.md。
